## Deployment Requirements

Before uploading the CSV to Pinterest:

1. Commit and deploy the new files in `assets/images/social/pinterest/how-often-change-air-filter/`.
2. Confirm each public image URL returns HTTP 200.
3. Confirm the destination URL works:
   `https://filter-wizard.com/how-often-change-air-filter.html`
4. If the live article remains under `/blog/how-often-change-air-filter.html`, add or verify a redirect before uploading.

## Upload Instructions

1. Deploy the site.
2. Open each public image URL in a browser to confirm it loads.
3. Download Pinterest's current bulk-create sample CSV.
4. Compare the sample headers with `how-often-change-air-filter-pins.csv`.
5. Copy the prepared values into Pinterest's official template if the headers differ.
6. Upload to the board `Air Filter & HVAC Tips`.
7. Review every Pin preview before publishing.
